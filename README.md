# Portfólio Pessoal — Projeto Final

Site portfólio desenvolvido para a disciplina de **Desenvolvimento de Interfaces** utilizando **HTML5**, **CSS3**, **Bootstrap 5** e **JavaScript**.

## Link do Site (GitHub Pages)

- **Portfólio publicado:** https://victorgabriel2912.github.io/github-pages/

## O que foi implementado

- **Apresentação & Sobre Mim:** Seção inicial e resumo com estatísticas e links de contato.
- **Projetos:** Carrossel interativo com os projetos desenvolvidos (*Velozes e Furiosos — Página de Filme*, *Breaking Bad — Página de Série*, *Blog do Desenvolvedor* e *Site de Companhia Aérea* no Figma).
- **Skills:** Grade responsiva com barras de progresso das tecnologias estudadas (HTML5, CSS3, Bootstrap, JavaScript, Figma, Git & GitHub e SQL).
- **Formulário de Contato com Validação em JS:** Validação de campos obrigatórios (`nome`, `assunto` e `mensagem`), verificação de `@` no `e-mail` e mínimo de 10 caracteres na `mensagem`, com destaque visual dos campos inválidos e alerta de erro.
